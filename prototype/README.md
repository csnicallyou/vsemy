# Консольный эксперимент «Летопись»

Отдельный **исследовательский срез** механик общения, знаний и интриг. Это НЕ готовая интеграция с Chronicle.Core из `csnicallyou/mygame` и не замена существующего `Chronicle.Cli`.

## Запуск (Windows, .NET 8 SDK)
Из папки `prototype/Chronicle.Prototyping`:

```powershell
dotnet run
```

Команды: `help`, `status`, `people`, `inspect 2`, `send 2 true`, `send 3 false`, `wait 3`, `journal`, `save game.json`, `load game.json`, `quit`.

## Что можно проверить
Начинаем за Мартина. Он слышал слух о казначее, но не знает объективную истину. Можно отправить письмо графу, подтвердив или отрицая слух. Доставка занимает 3 дня и стоит 2 серебра. Получатель обновляет **своё** убеждение на основании доверия к отправителю. Его знание не показывается игроку напрямую; в журнале видно только доставку, но не скрытую оценку. Слух не равен факту. Состояние можно сохранять и загружать.

## Разделение ответственности
`Domain.cs` не обращается к консоли или Godot. `Program.cs` — только ввод/вывод. Правила должны в дальнейшем мигрировать в актуальный `Chronicle.Core` после согласования интерфейсов, ID, моделей фактов, тиков, команд и версий сохранений; **не копировать второй World поверх основного**.

## Ограничения
Это небольшой демонстратор, а не обещание полноценной модели. Нет самостоятельных NPC-планов, встреч, проверок истины, перехвата писем, доказательств, долговременной памяти и системы судов. Не тестировалось локальной сборкой: в рабочем окружении отсутствует SDK .NET. Нужна проверка `dotnet run` на Windows перед переносом в основной проект.
